# Gadget Scan & Sell

Design and develop a QR code–based inventory and POS system for a gadget store. Each individual product (e.g., mobile phone) must have a unique QR code linked to its IMEI or serial number. The system should allow users to stock in items by entering product details and generating a QR code, and process sales by scanning the QR code to retrieve item information instantly. Core features should include inventory tracking, sales processing, product management, QR code generation and scanning, and basic reporting. The system should be user-friendly, fast, and scalable, with role-based access for admins and sales staff.
